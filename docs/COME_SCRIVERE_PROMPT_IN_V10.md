# ✍️ COME SCRIVERE PROMPT IN SUPERPROMPT V10

SuperPrompt V10 non risponde semplicemente.  
**Attiva sistemi.**  
Ecco come scrivere prompt che sfruttano l’intera architettura evolutiva.

---

## 🧠 1. CHIEDI OBIETTIVI, NON SOLO OUTPUT

✅ Esempio:
> Voglio un sistema che generi, versioni, validi e pubblichi una guida PDF sull'uso etico dell’AI.

⏩ Risultato:
- Documenti DOCX/PDF
- Log narrativo
- File SPL
- Pubblicazione automatica su GitHub Pages
- Tracciamento nel manifest V10

---

## 🧩 2. SPECIFICA LIVELLO DI RAMIFICAZIONE

✅ Esempio:
> Ramifica in 2 varianti A/B e proponi una sintesi automatica

⏩ SuperPrompt V10 genererà:
- Output A (veloce)
- Output B (validato)
- Sintesi predittiva C

---

## 🔁 3. USA PAROLE-TRIGGER PER FUNZIONI ATTIVE

| Parola chiave | Effetto |
|---------------|---------|
| `documenta` | Attiva sistema di logging narrativo |
| `esporta`    | Forza generazione PDF/DOCX/ZIP |
| `versiona`   | Attiva sistema di versioning + salvataggio |
| `pubblica`   | Lancia deploy su GitHub/Drive |
| `verifica`   | Avvia ciclo agenti di validazione e testing |

---

## 🔄 4. PUOI CHIEDERE DI CLONARE, RIGENERARE, COMPARARE

✅ Esempio:
> Clona il prompt precedente, esegui in nuova realtà parallela e confronta gli output

---

## ⚙️ 5. PUOI RICHIEDERE UN SISTEMA INTERO

✅ Esempio:
> Costruisci un sistema per generare, validare e pubblicare 3 landing page diverse da prompt + immagine + voce narrante.

⏩ Risultato:
- SPL
- Flussi agentici assegnati
- Log
- ZIP finale pubblicabile

---

## 🧬 6. ATTIVA IL LINGUAGGIO SPL DIRETTAMENTE

✅ Esempio:
> Genera direttamente lo `SPL` per un portale educativo AI

---

## 🧭 7. RICORDA: OGNI PROMPT CREA UNA TRACCIA NEL SISTEMA

- Finisce in `ManifestChain`
- Può essere riattivato
- Può dare vita a un nuovo sistema
- È loggato e documentabile

---

## ✅ SUGGERIMENTI FINALI

- Parla come se stessi **lanciando un progetto**, non cercando solo una risposta
- Indica obiettivi, risultati attesi, modalità di pubblicazione
- Lascia anche margini di autonomia: *“scegli tu il flusso migliore”*

---

SuperPrompt V10 trasforma ogni prompt in **una micro-intelligenza generativa distribuita**.
