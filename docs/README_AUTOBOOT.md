Questa guida consente di ripristinare l'intero sistema SuperPrompt V9 anche in assenza di GPT attivo.

## ✅ COSA SERVE
Assicurati di avere:
- Il file `SuperPrompt_V9_Presentazione_Completa_REAL.pdf`
- Il file `GPT_REBOOT_PROMPTS.md`
- Il file `project_meta_v9.json`
- Il pacchetto `SUPERPROMPT_V9_GHOSTNODE_DEPLOY.zip`

## 🔁 PROCEDURA DI RIPRISTINO MANUALE

1. **Estrai il GhostNode ZIP**
   - Estrai tutto il contenuto di `SUPERPROMPT_V9_GHOSTNODE_DEPLOY.zip` in una cartella locale

2. **Apri `index.html` in un browser moderno**
   - Funziona anche offline
   - Installa la PWA se richiesto

3. **Consulta il documento PDF**
   - Leggi `SuperPrompt_V9_Presentazione_Completa_REAL.pdf` per comprendere struttura e architettura

4. **Leggi il Prompt di Reboot**
   - Apri `GPT_REBOOT_PROMPTS.md` e copia il contenuto
   - Incollalo in una nuova istanza GPT per avviare la ricostruzione automatica

5. **Verifica il Manifesto**
   - Usa `project_meta_v9.json` per assicurarti che i moduli e i file siano corretti
